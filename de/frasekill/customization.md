# Anpassung

Jeder der 3 Slots speichert eine vollständige eigene Konfiguration: Phrase, Farbe, Leuchten und Intensität, Schriftart, Größe, Position, Animation, Geschwindigkeit sowie Einstellungen für den Killer-Text. Jeder Slot kann außerdem in den Zufallsmodus ein- oder ausgeschlossen werden.

## Live-Vorschau

FraseKill kann direkt im Vorschau-Rahmen verschoben werden. Unterstützte Formate: 16:9, 16:10, 4:3, 5:4 und 21:9. Der Wiederholen-Button spielt nur die Vorschau erneut ab und erzeugt keine Schleife bei echten Kills.

## Preset kopieren

Eine komplette Slot-Konfiguration kann in einen anderen Slot kopiert und anschließend angepasst werden.

## Menüfarben

Die globalen UI-Farben befinden sich am Ende von `web/styles.css` im Block `ZBROU FRASEKILL THEME`. So kann das Design geändert werden, ohne JavaScript anzufassen.
