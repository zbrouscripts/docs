# FraseKill for FiveM

**ZBrou FraseKill** is a standalone FiveM resource that lets players create custom kill phrases shown to the victim after a valid player kill. It is designed for PvP and roleplay servers and keeps phrases, access, rules and preferences persistent in SQL.

## Main features

- 3 complete phrase slots per player.
- Fixed or random slot mode.
- 100 fonts and 25 animations plus None.
- Phrase and killer-name styling, glow, size, position and animation speed.
- Live preview.
- Classic and optional Liquid Glass appearance.
- 8 interface languages: EN, ES, PT, FR, TR, DE, IT and PL.
- Managed access, managed access + Tebex, or a custom server-side check.
- Owner ACE plus delegated administrators with granular permissions.
- Rules, blocked words and server-side moderation.
- Script Settings panel with file/panel configuration modes and Restore defaults.
- Automatic medical-resource detection with multiple ambulance adapters.
- In-memory caches so normal kills do not constantly query SQL.
