# FraseKill for FiveM

**ZBrou FraseKill** lets players customize the message their victim sees after a kill. The resource is designed for both PvP and roleplay servers and stores player settings persistently in the database.

## Main features

- 3 complete presets per player.
- Fixed or random mode across enabled presets.
- 100 fonts and multiple animations with adjustable speed.
- Configurable color, glow, size, position and killer text.
- Live preview for multiple aspect ratios.
- Persistent access by player, job, gang/group, ACE or Tebex.
- Permanent or timed access with expiration warnings.
- Built-in administration panel.
- Optional Discord webhook logs.
- In-memory caching to avoid constant SQL queries during kills.

Start with **Installation**, then open **Configuration** to adapt the resource to your server.
