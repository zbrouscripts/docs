# FraseKill for FiveM

**ZBrou FraseKill** lets each player create a custom kill phrase and choose how it looks when they eliminate another player.

Changes are saved automatically, so players keep their phrases and preferences when they join the server again.

## Main features

- 3 FraseKill slots per player.
- Fixed or random mode.
- 100 fonts and 25 animations.
- Colours, glow, size, position and speed.
- Custom killer-name style.
- Live preview before saving.
- Classic and optional Liquid Glass appearance.
- 8 languages: EN, ES, PT, FR, TR, DE, IT and PL.
- Managed access with optional Tebex support.
- Admin panel with separate administrator permissions.
- Rules and blocked words.
- Compatibility with several ambulance jobs.
- Script settings from files or from the visual panel.

If this is your first setup, start with **Installation** and then open **Configuration**.
