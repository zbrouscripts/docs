# Details and related terms

ZBrou FraseKill is a **FiveM kill phrase / kill message script** for custom text shown after a player kill. It can also be described as **PhraseKill**, **FiveM kill phrase**, **custom kill message**, **death message**, **kill text** or **PvP kill message**.

FraseKill is independent from ImagenKill. It focuses on text presets, animations, access control, rules, administration and integrations.

For production servers, use server-side validation, test the exact medical/framework combination and keep secrets in private server files.
