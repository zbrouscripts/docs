# Interface and appearance

Use this section to match FraseKill to your server style.

## Default language

Choose the language from the dropdown:

- English
- Español
- Português
- Français
- Türkçe
- Deutsch
- Italiano
- Polski

The default language is **English**.

## Theme

Choose between:

- **Classic** — solid dark design.
- **Liquid Glass** — glass-style design.

Liquid Glass is disabled by default.

## Menu colours

There are three separate colours:

- **Detail colour** — active buttons, switches, selected slot and highlights.
- **Background colour** — main menu background.
- **Base colour** — cards, fields, inactive slots and inner blocks.

Each colour has a picker and all three include a reset button.

## Logo

To use your own logo, replace:

```text
web/logo.png
```

with your image and keep the same filename.
