# FraseKill defaults

Choose how FraseKill should look when a player first uses it.

Players can still change their own phrase and appearance later if they have access.

## Slot mode

- **Fixed** — always uses the slot selected by the player.
- **Random** — rotates between enabled slots so different kills can show different phrases.

## Default values

You can choose:

- starting phrase and character limit;
- phrase colour, **opacity**, size, glow, font and animation;
- killer-line colour, **opacity, glow**, size, alignment, font and animation;
- whether FraseKill starts enabled.

Every setting includes a `?` with a simple explanation.

## Preview

Players can preview their FraseKill before saving it.

Replay preview only replays the animation inside the editor.
