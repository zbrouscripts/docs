# FraseKill para FiveM

**ZBrou FraseKill** permite que los jugadores personalicen el mensaje que verá su víctima después de una baja. El recurso está pensado tanto para servidores PvP como para servidores roleplay y mantiene la configuración persistente en base de datos.

## Funciones principales

- 3 configuraciones completas por jugador.
- Modo fijo o aleatorio entre presets habilitados.
- 100 tipografías y múltiples animaciones con velocidad ajustable.
- Color, brillo, tamaño, posición y texto del killer configurables.
- Vista previa en vivo para varias relaciones de aspecto.
- Permisos persistentes por jugador, job, gang/grupo, ACE o Tebex.
- Accesos permanentes o temporales con avisos de caducidad.
- Panel de administración integrado.
- Logs opcionales mediante Discord webhook.
- Caché en memoria para evitar consultas SQL constantes durante las kills.

Empieza por **Instalación** y continúa con **Configuración** para adaptar el recurso a tu servidor.
