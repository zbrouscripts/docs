# FraseKill para FiveM

**ZBrou FraseKill** es un recurso independiente para FiveM que permite a los jugadores crear frases de kill personalizadas que ve la víctima después de una kill válida. Está pensado para servidores PvP y roleplay y mantiene frases, accesos, normas y preferencias guardados en SQL.

## Funciones principales

- 3 slots completos de FraseKill por jugador.
- Modo fijo o aleatorio.
- 100 tipografías y 25 animaciones más Ninguna.
- Estilo independiente para la frase y el nombre del killer.
- Preview en directo.
- Apariencia Classic y Liquid Glass opcional.
- 8 idiomas: EN, ES, PT, FR, TR, DE, IT y PL.
- Acceso gestionado, acceso gestionado + Tebex o comprobación personalizada server-side.
- ACE solo para el owner y administradores delegados con permisos granulares.
- Normas, palabras bloqueadas y moderación server-side.
- Ajustes del script con modo archivos/panel y botón de restablecer predeterminado.
- Detección automática de recursos de ambulance con varios adaptadores.
- Cachés en memoria para evitar consultas SQL constantes durante las kills.

Empieza por **Instalación** y después revisa **Configuración** y **Ajustes del script**.
