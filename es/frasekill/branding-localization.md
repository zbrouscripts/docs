# Marca e idiomas

## Logo

Sustituye `web/logo.png` por tu PNG y mantén el mismo nombre. El archivo está fuera del escrow para que el owner pueda cambiarlo fácilmente.

## Colores del menú

```lua
Config.UI.AccentColor = '#0e58d8'
Config.UI.BackgroundColor = '#15181e'
Config.UI.BaseColor = '#1a1e25'
```

Los tres colores son independientes y también tienen selector en Ajustes del script. Classic sigue siendo sólido. Cambiar colores **no** activa Liquid Glass.

## Idiomas

El idioma por defecto es inglés. El selector incluye English, Español, Português, Français, Türkçe, Deutsch, Italiano y Polski. La preferencia del jugador se guarda y tanto la UI normal como Admin usan el mismo sistema de traducciones.
