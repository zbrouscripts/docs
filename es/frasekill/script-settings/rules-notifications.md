# Normas y notificaciones

## Normas

Puedes decidir si los jugadores pueden consultar las normas desde **View rules**.

Las normas y las palabras bloqueadas se administran desde el panel.

Si una frase no cumple las reglas del servidor, FraseKill puede impedir que se guarde.

## Notificaciones

Puedes activar o desactivar los avisos y logs de administración.

También puedes cambiar el nombre que aparecerá en los mensajes enviados a Discord.

Las URLs de webhook no se muestran en el panel y se guardan en:

```text
server/webhooks.lua
```
