# Detección de muerte

Este apartado decide **cuándo debe aparecer FraseKill**.

En la mayoría de servidores puedes dejar el sistema en **Auto** y FraseKill intentará detectar el ambulance job que estés usando.

También puedes elegir si FraseKill debe aparecer cuando el jugador queda incapacitado o cuando ya se considera muerto, dependiendo de cómo funcione tu medical.

Si usas un ambulance compatible, normalmente no necesitas tocar nada más.

Consulta **Compatibilidad médica** para ver la lista de scripts reconocidos.
