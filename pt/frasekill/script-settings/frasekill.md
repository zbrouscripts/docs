# FraseKill e valores predefinidos

Escolhe como FraseKill aparece quando um jogador o usa pela primeira vez.

- **Fixo** — usa sempre o slot selecionado.
- **Aleatório** — alterna entre slots ativos para mostrar frases diferentes.

Podes definir frase inicial, limite de caracteres, ativação, cor, tamanho, brilho, tipo de letra, animação, velocidade e aparência do nome do killer.

Cada opção tem um `?` com uma explicação simples.

A pré-visualização permite ver o resultado antes de guardar.
