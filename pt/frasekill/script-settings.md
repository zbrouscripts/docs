# Definições do script

Aqui podes preparar FraseKill para o teu servidor sem editar todas as opções manualmente.

No topo escolhes entre **Ficheiros de configuração** e **Painel de administração**. Só o owner principal pode alterar este modo.

Quando usas ficheiros, o resto do painel fica escurecido e bloqueado.

## Restaurar predefinições

O botão **Restaurar predefinições** devolve as definições do script aos valores originais sem apagar frases, acessos, regras, palavras bloqueadas ou administradores.

Os três principais seletores de cor também têm o seu próprio botão de reset.
