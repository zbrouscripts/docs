# GitBook site settings

This repository uses the current site-wide Git Sync format in `gitbook-docs.yaml`.

The file contains a top-level `site:` key and maps each language directory as a space/variant under the Documentation section.

Recommended branding:

- Primary color: `#0E58D8`
- Style: dark, clean and minimal
- Use the ZBrou logo from `assets/brand/zbrou-logo.png`

If GitBook reports `expected "site" to be defined`, make sure the repository contains the `gitbook-docs.yaml` included in this package at the repository root.
