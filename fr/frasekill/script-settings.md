# Réglages du script

Cette section permet de préparer FraseKill sans modifier chaque option dans les fichiers.

Choisis **Fichiers de configuration** ou **Panneau d'administration**. Seul l'owner principal peut changer ce mode.

Quand les fichiers sont utilisés, le reste du panneau est grisé et verrouillé.

## Restaurer les valeurs par défaut

Le bouton global remet les réglages du script à leur état d'origine sans supprimer les phrases, accès, règles, mots bloqués ou administrateurs.

Les trois couleurs principales ont aussi leur propre bouton de reset.
