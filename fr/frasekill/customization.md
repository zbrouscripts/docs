# Personnalisation

Chaque slot possède sa propre configuration complète : phrase, couleur, lueur et intensité, police, taille, position, animation, vitesse et réglages du texte du killer. Chaque slot peut aussi être inclus ou exclu du mode aléatoire.

## Aperçu en direct

Déplacez FraseKill directement dans la zone d’aperçu et testez les formats 16:9, 16:10, 4:3, 5:4 et 21:9. Le bouton de répétition rejoue uniquement l’animation dans l’aperçu ; il ne crée pas de boucle pendant une vraie kill.

## Copier un preset

Une configuration complète peut être copiée d’un slot vers un autre avant d’être modifiée.

## Couleurs du menu

Les couleurs globales se trouvent à la fin de `web/styles.css` dans le bloc `ZBROU FRASEKILL THEME`, ce qui permet de recolorer l’interface sans modifier JavaScript.
