# Détection de mort

Cette section décide **quand et où FraseKill peut apparaître**.

Dans la plupart des cas, laisse le medical sur **Auto**.

## Zones de mort

Les zones ne donnent jamais l'accès joueur. Le killer doit toujours posséder son accès FraseKill.

- **Extérieur autorisé + zone Bloquer** — fonctionne partout sauf dans ces zones.
- **Extérieur bloqué + zone Autoriser** — fonctionne uniquement dans les zones autorisées.

Une zone bloquée est prioritaire en cas de chevauchement.

Le panel peut prendre ta position actuelle et afficher le rayon dans le monde. Bleu = autoriser, rouge = bloquer.

La validation réelle se fait côté serveur avec la position de mort de la victime.
