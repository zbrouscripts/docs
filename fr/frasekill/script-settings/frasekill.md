# FraseKill et valeurs par défaut

Définis l'apparence initiale de FraseKill.

- **Fixe** — utilise toujours le slot sélectionné.
- **Aléatoire** — alterne entre les slots actifs pour varier les phrases.

Tu peux régler la phrase initiale, la limite de caractères, l'activation, la couleur, la taille, la lueur, la police, l'animation, la vitesse et le nom du killer.

Chaque option possède un `?` avec une explication simple.
