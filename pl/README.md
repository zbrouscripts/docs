# Dokumentacja ZBrou Scripts

Oficjalna dokumentacja zasobów **ZBrou** dla FiveM.

Wybierz zasób z menu bocznego, aby zobaczyć instalację, konfigurację, uprawnienia, personalizację i integracje.

## Dostępne zasoby

- **FraseKill** — własne frazy po zabójstwie, presety, animacje, uprawnienia i panel administracyjny.
