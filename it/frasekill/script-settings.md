# Impostazioni script

Questa sezione ti permette di preparare FraseKill senza modificare ogni opzione nei file.

Scegli **File di configurazione** o **Pannello di amministrazione**. Solo l'owner principale può cambiare questa modalità.

Con i file di configurazione, il resto del pannello viene oscurato e bloccato.

## Ripristina predefiniti

Il reset globale ripristina le impostazioni dello script senza cancellare frasi, accessi, regole, parole bloccate o amministratori.

I tre colori principali hanno anche un reset separato.
