# Rilevamento morte

Questa sezione decide **quando FraseKill deve apparire**.

Nella maggior parte dei server puoi lasciare **Auto**. FraseKill proverà a rilevare l'ambulance job usato.

Puoi anche scegliere tra incapacitated e dead in base al tuo medical.

Vedi **Compatibilità medica** per la lista supportata.
